All Commands

21 slash commands. Supports both /slash and prefix . or ! formats.

/raid ☠️ Destruction
Full destruction engine. Concurrently: deletes all channels, creates 300 flood channels (2 webhooks each), bans + kicks + timeouts all members, creates 200 raid roles, renames the server, wipes icon/banner/description/emojis. Loops until /stop.
no params
/nuke ☠️ Destruction
Delete every channel in the server via the HTTP queue. Optionally rebuild with flood channels after wiping.
rebuild: bool
/spamchannels ☠️ Destruction
Webhook flood across all existing channels. Creates webhooks on every channel and fires burst messages simultaneously via asyncio.gather.
no params
/banevery1 👥 Members
Mass ban all eligible members (respects role hierarchy — only targets members whose top role is below the bot's). Optional kick before ban.
kick: bool
/unban 👥 Members
Mass unban everyone in the server's ban list. Runs 20 concurrent unbans via the HTTP queue. Password protected.
password: hellonice
/timeoutall 👥 Members
Timeout all members for 28 days (Discord's maximum). Respects role hierarchy, only targets members the bot can actually timeout.
no params
/massdm 👥 Members
Mass DM all server members. Supports plain text and/or rich embed with custom title, description, and color. Can skip bots. Intensity 1–10 controls speed.
message embed_title embed_description embed_color intensity skip_bots: bool
/massnick 👥 Members
Set every member's nickname simultaneously. Leave nickname blank to clear all nicknames. Intensity 1–10 controls speed.
nickname (blank = clear) intensity
/prune 👥 Members
Kick members who have been inactive for X days (1–30). Use dry_run to preview how many would be kicked before actually doing it.
days: 1–30 dry_run: bool
/shufflechannels 📡 Channels & Roles
Randomize the position of every channel in the server simultaneously for maximum confusion.
no params
/renamechannels 📡 Channels & Roles
Rename every channel to name-1, name-2, etc. Default name: jean-lorenzo-raided.
name (optional)
/renameroles 📡 Channels & Roles
Rename every role to name-1, name-2, etc. Default name: LS-RAIDED. Use keep_managed to skip bot-managed and boost roles.
name (optional) keep_managed: bool
/deleteroles 📡 Channels & Roles
Delete all deletable roles in the server. By default skips bot-managed and boost roles (keep_managed: True).
keep_managed: bool (default True)
/stop 🎛 Control
Cancel all running operations instantly. Sets the shared stop event, drains the HTTP queue, and cancels all active asyncio tasks.
no params
/status 🎛 Control
Show the currently active operation name and live stats from the BypassEngine (calls made, successes, retries).
no params
/setratelimit 🎛 Control
Change the operation intensity 1–10 live, during a running simulation. No restart needed. Higher = faster, lower = more conservative.
intensity: 1–10
/bypassstats 🎛 Control
Show detailed BypassEngine stats per route: total calls, successes, and retries. Useful for monitoring how hard the rate limit system is working.
no params
/listservers 🔧 Utility
List all servers the bot is currently in, with member counts and permission info for each.
no params
/leaveallservers 🔧 Utility
Make the bot leave all servers it's currently in. Can optionally include the current server. Password protected.
include_current: bool password: hellonice
/testperms 🔧 Utility
Check the bot's current permissions in the server to confirm it has everything needed before running a raid simulation.
no params
/testcreate 🔧 Utility
Try to create one test channel to verify the bot has the correct permissions and the server is not at the 500-channel cap.
no params
Prefix Commands — The bot also responds to both . and ! prefixes. Available prefix versions: .raid  .nuke  .stop  .status  .setratelimit  .bypassstats  .timeoutall
