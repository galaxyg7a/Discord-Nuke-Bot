About the Bot

The Eonizer is a private Discord nuke bot built to destroy servers completely. Created by EoN. Private access only.

What It Does

☠️
Total Server Destruction
Wipes every channel, deletes every role, removes all emojis, resets the server icon and name. Leaves the server completely unusable.
👥
Mass Member Operations
Bans, kicks, and timeouts every member in the server simultaneously. Nicknames overwritten. No one is spared.
📡
Channel Flood & Webhook Spam
Creates 300 flood channels and fires continuous webhook message bursts across all of them. Every channel fills instantly with noise.
🔁
Infinite Loop
Runs a continuous cycle of destruction — nuke, rebuild, spam, repeat — until manually stopped with /stop.
🎛
Live Speed Control
Intensity adjustable 1–10 in real-time during a running operation. No restart needed — full control mid-execution.

How /raid Works

All phases launch concurrently the moment you run the command. Nothing is sequential.

Phase 1
Rename & Lock Server
Renames the server and strips all @everyone permissions so no one can do anything.
Phase 2
Wipe Server Identity
Removes server icon, banner, description, and stickers. Server identity is completely erased.
Phase 3
Emoji Wipe
Every custom emoji in the server is deleted.
Phase 4
Channel Nuke + Flood Loop
All existing channels are deleted. 300 flood channels are created and immediately hit with webhook spam. This loop runs until /stop.
Phase 5
Role Flood
200 new roles are created simultaneously, flooding the role list entirely.
Phase 6
Member Wipe
Every member is kicked, banned, timed out for 28 days, and has their nickname overwritten — all at the same time.
